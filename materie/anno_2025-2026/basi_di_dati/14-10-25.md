## Linguaggi per basi di dati

Linguaggi per la **definizione dei dati**: specificare i nomi delle tabelle, gli attributi, i nomi degli attributi, il dominio degli attributi

Linguaggi per la **manipolazione dei dati**: interrogazione, inserimento, cancellazione e modifica dei dati.
Linguaggi di interrogazione e di aggiornamento
Linguaggi di interrogazione procedurali e non procedurali

SQL è sia DDL che DML

## Gestore di una base di dati
Il modulo software che realizza l'interfaccia

## Amministratore di una base di dati
Responsabile dei dati e delle relative procedure di accesso.

## Utenti di una base di dati

Utenti naive: utenti che interagiscono con un database senza saperlo

Utenti che sviluppano programmi applicativi: usano l'API della base di dati senza conoscere nulla del database

Utenti sofisticati: utilizzano direttamente il DML

## DBMS

Livello fisico: livello dei file
+ Data dictionary
+ Statistical data: dati quantitativi (es. quante righe una tabella contiene, variabilità di un attributo)
+ Indici: strutture per trovare più velocemente i dati
	+ primari
	+ secondari

Gestore della memoria: modulo che interagisce con la memoria sottostante
+ quello che gestisce le transazioni

Query Processor: interrogazione del database
